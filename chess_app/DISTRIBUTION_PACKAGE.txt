INSTALLATION INSTRUCTIONS FOR END USERS:
=========================================

1. Extract zip file
2. Install Python 3.10+ (if not installed)
3. Install dependencies: pip install PyQt5 python-chess
4. Run: python main.py

OR

1. Extract zip file
2. Run build_exe.bat (requires PyInstaller)
3. Run: dist\ChessApp.exe (no Python required)
