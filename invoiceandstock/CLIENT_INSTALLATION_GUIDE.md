# 📦 Pharmacy Invoice Generator - Client Installation Guide

## ✅ Requirements for Fresh Windows Machine

### Minimum System Requirements:
- **Windows 10** or **Windows 11** (64-bit)
- **No Python installation needed** - .exe file is standalone
- **No additional software needed** - Everything is bundled

### Optional (if needed):
- **Visual C++ Redistributables** (usually already installed with Windows)
  - If missing, download from: https://aka.ms/vs/17/release/vc_redist.x64.exe
  - This is rarely needed as Windows 10/11 usually has it

## 🚀 Installation Steps

### Step 1: Copy Files
1. Copy `PharmacyInvoiceGenerator.exe` to client's desktop or any folder
2. (Optional) Copy `medicines.xlsx` if you want to include sample data

### Step 2: Run Application
1. Double-click `PharmacyInvoiceGenerator.exe`
2. Application will start automatically
3. No installation needed!

## 📋 What's Included in .exe File

✅ **All Python dependencies** - Bundled inside
✅ **All libraries** - pandas, reportlab, openpyxl, tkinter
✅ **All code** - Complete application

## ⚠️ Important Notes

1. **First Run**: Application might take 5-10 seconds to start (extracting bundled files)
2. **Antivirus**: Some antivirus might flag .exe file (false positive) - Add to exceptions if needed
3. **Windows Defender**: Might show "Unknown Publisher" warning - Click "Run anyway"
4. **Firewall**: No internet connection needed - Application works offline

## 🐛 Troubleshooting

### If .exe doesn't start:
1. Check Windows version (Windows 10/11 required)
2. Try running as Administrator
3. Check if antivirus is blocking it
4. Install Visual C++ Redistributables (link above)

### If authorization error appears:
- Contact administrator with the Machine ID shown in error
- Machine ID will be added to authorized list
